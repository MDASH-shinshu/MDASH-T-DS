// 説明スライド: 回帰分析の基本概念
::Q1.1 回帰分析の目的::回帰分析の主な目的として最も適切なものはどれか？{
=説明変数と目的変数の関係性を数式モデルとして表し、予測や解釈に利用すること
~説明変数同士の相関をゼロにすること
~目的変数の分布を一様分布に近づけること
~外れ値をすべて除去すること
}

// 説明スライド: 単回帰と重回帰
::Q1.2 単回帰と重回帰::次のうち、重回帰モデルの特徴として正しいものをすべて選べ。{
~%33.33333% 複数の説明変数を同時に用いて目的変数を説明する
~%33.33333% 各説明変数の係数は他の変数の影響を調整したうえで推定される
~%33.33333% 説明変数間に強い相関があると係数の解釈が難しくなる
~%-100% 説明変数が1つしかないときにのみ定義される
}

// 説明スライド: 最小二乗法の考え方
::Q1.3 最小二乗法::線形回帰モデルのパラメータ推定で最小二乗法を用いる主な理由として最も適切なものはどれか？{
=残差二乗和を最小にする解を解析的に求めやすく、正規誤差の仮定のもとで最尤推定にも対応するから
~必ず誤差が0になる解が得られるから
~説明変数の分布を一様にできるから
~どのような誤差分布でも常に最適であるから
}

}

// 説明スライド: 多項式回帰・過学習
::Q1.5 モデルの複雑さと過学習::訓練データに対して高次多項式回帰モデルを当てはめたところ、訓練誤差は非常に小さいが、新しいデータに対する予測誤差が大きくなった。この現象の説明として最も適切なものはどれか？{
=モデルの自由度が高すぎて訓練データに過度に適合し、過学習が生じている
~訓練データの数が多すぎてモデルが単純化されている
~線形モデルは常に過学習を起こさないため、別の原因である
~最小二乗法ではこのような現象は決して起こらない
}

// 説明スライド: 正則化（リッジ回帰）
::Q1.6 リッジ回帰の効果::リッジ回帰（L2正則化付き最小二乗法）の効果として最も適切な説明はどれか？{
=回帰係数の大きさにペナルティを課すことで、分散を抑えつつ過学習のリスクを軽減する
~説明変数の数を自動的に削減し、不要な変数の係数を完全に0にする
~誤差分布を正規分布から一様分布に変換する
~目的変数の外れ値を自動的に除去する
}

// 説明スライド: 訓練誤差とテスト誤差
::Q1.7 汎化性能の評価::回帰モデルの性能評価において、訓練誤差だけでなくテスト誤差を評価する理由として最も適切なものはどれか？{
=訓練データに対する当てはまりが良くても、新しいデータに対する予測精度が低い場合があるから
~訓練誤差は常に0になるため
~テスト誤差は訓練誤差より必ず小さいため
~テスト誤差の計算には目的変数が不要だから
}

// 説明スライド: ロジスティック回帰と線形回帰の違い
::Q1.8 ロジスティック回帰との比較::線形回帰とロジスティック回帰の違いとして最も適切な説明はどれか？{
=線形回帰は連続値を予測するのに対し、ロジスティック回帰は確率（0〜1）を出力して2値分類に用いられる
~線形回帰は2値目的変数にしか使えない
~ロジスティック回帰は目的変数が必ず正規分布であることを仮定する
~ロジスティック回帰では説明変数をまったく使わない
}

// 説明スライド: 回帰係数の解釈
::Q1.9 回帰係数の解釈::線形回帰モデル  y = β0 + β1 x1 + β2 x2 + ε  における係数 β1 の解釈として最も適切なものはどれか？{
=他の変数 x2 を一定に保ったとき、x1 が1単位増加したときの y の平均的な増加量
~x1 の標準偏差が1増えたときの y の増加量
~x1 が0のときの y の平均値
~x1 と x2 の共分散
}

::Q1.10 ロジスティック関数の性質::ロジスティック回帰で用いられるロジスティック関数 f(z) = 1 / (1 + exp(-z)) の性質として正しいものをすべて選べ。{

~%33.33333% z が大きくなると f(z) は1に近づく
~%33.33333% z が小さくなると f(z) は0に近づく
~%-100% 任意の z に対して f(z) は必ず0か1のどちらかになる
}

// 説明スライド: ロジットとオッズ
::Q1.11 ロジット変換::ロジスティック回帰において、確率 p をロジット変換した log(p/(1-p)) を用いる主な利点として最も適切なものはどれか？{
=確率 p を実数全体に写像し、説明変数との線形関係としてモデル化しやすくする
~確率 p を0か1のいずれかに丸めることができる
~確率 p の平方根をとることで分散を一定にする
~オッズそのものを0〜1の範囲に収めるため
}

// 説明スライド: オッズ比の解釈
::Q1.12 オッズ比::ロジスティック回帰モデルにおいて、ある説明変数 x の係数が正の場合、その説明変数の増加に伴うオッズ比の変化として最も適切な説明はどれか？{
=x が1増加するとき、事象が起こるオッズが exp(係数) 倍になる
~x が1増加するとき、事象が起こる確率が必ず exp(係数) 増加する
~x が1増加するとき、事象が起こる確率が1から減少する
~x が1増加するとき、事象が起こるオッズが1/exp(係数) 倍になる
}

// 説明スライド: 目的変数と誤差構造
::Q1.13 ロジスティック回帰の誤差構造::ロジスティック回帰において、線形回帰と異なり最小二乗法ではなく最尤法で推定する主な理由として最も適切なものはどれか？{
=目的変数が0/1のベルヌーイ分布に従うと考えられ、二乗誤差よりも尤度に基づく推定が自然だから
~最小二乗法では常に発散してしまうから
~ロジスティック回帰では誤差が存在しないから
~最尤法を用いると常に誤差が0になるから
}

// 説明スライド: 閾値と分類性能
::Q1.14 閾値の選択::ロジスティック回帰では出力された確率に対して閾値（例えば0.5）を設けてクラスを決定する。この閾値の変更が主に影響を与える評価指標として最も適切なものはどれか？{

// 説明スライド: 不均衡データ

// 説明スライド: 時系列と独立性

// 説明スライド: トレンドと季節性

// 説明スライド: 1期先予測と長期予測
