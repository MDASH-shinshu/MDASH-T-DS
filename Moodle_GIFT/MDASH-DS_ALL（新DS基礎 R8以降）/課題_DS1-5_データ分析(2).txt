// クラスター分析 基本概念
//////////////////////////////////////////////////////////////

::Q1.1 クラスター分析の目的::クラスター分析の主な目的として最も適切なものはどれか？{
=「似ている」サンプル同士をグループ化し、データの構造を把握すること
~目的変数との線形関係を推定すること
~目的変数の確率を推定して分類器を構成すること
~将来の時系列値を予測すること
}

// クラスター分析 距離の定義
::Q1.2 「似ている」の定義::クラスター分析において「似ている／似ていない」を定量的に表すために最も基本的に用いられるものはどれか？{
=サンプル間の距離（例: ユークリッド距離）
~サンプルの出現頻度
~サンプルの時系列順序
~サンプルのクラスラベル
}

// 階層的クラスタリング
::Q1.3 階層的クラスタリングの特徴::階層的クラスタリングの特徴として正しいものをすべて選べ。{
~%33.33333% デンドログラム（樹形図）として階層構造を可視化できる
~%33.33333% クラスタ数をあとから柔軟に変えて「切り出す」ことができる
~%33.33333% サンプル数が多いと計算量が大きくなりやすい
~%-100% あらかじめクラスタ数を指定しなければ適用できない
}

// 非階層クラスタリング（k-means）
::Q1.4 k-meansの性質::k-means 法に関する説明として最も適切なものはどれか？{
=クラスタ中心と各サンプルとの距離二乗和を最小にするようにクラスタと中心を反復的に更新する
~クラスタ間距離を最大化するように木構造を作る
~クラスラベル付きデータを用いて分類境界を学習する
~時間情報を用いて系列を分割する
}

// k-meansの初期値依存性
::Q1.5 初期値と局所解::k-means 法を異なる初期クラスタ中心で複数回実行したところ、異なるクラスタリング結果が得られた。この現象の説明として最も適切なものはどれか？{
=目的関数が凸ではないため、初期値に応じて異なる局所最適解に収束しうる
~アルゴリズムが確率的勾配降下法を使っていないため
~距離を使わないアルゴリズムだから
~k-means では常に一意の解が得られるはずなので実装バグである
}

// 標準化の有無
::Q1.6 標準化の影響::クラスター分析を行う前に変数ごとに平均0・分散1に標準化する主な目的として最も適切なものはどれか？{
=スケールの異なる変数が距離計算に与える影響を均等にするため
~外れ値を自動的に除外するため
~変数間の相関を完全に0にするため
~クラスタ数を自動決定するため
}

// クラスタ間距離の定義
::Q1.7 クラスタ間距離の違い::階層的クラスタリングにおいて、クラスタ間距離の定義（単連結法・完全連結法・群平均法・ウォード法など）を変えると何が変わるか？{
=デンドログラムの形と最終的なクラスタ構造が変わる
~各サンプルの元の座標値が変わる
~サンプル数が変わる
~距離計算が不要になる
}

// デンドログラムの切り方
::Q1.8 デンドログラムの解釈::デンドログラムを用いてクラスタ数を決める際の典型的な判断基準として最も適切なものはどれか？{
=縦軸の距離が大きく「飛んでいる」ところで水平に切り、その下の枝数をクラスタ数とする
~葉の数と同じ数だけクラスタを取る
~常にクラスタ数2で切る
~常にクラスタ数をサンプル数の平方根にする
}

// クラスタリングの評価
::Q1.9 クラスタの妥当性::教師なしのクラスタリング結果が妥当かどうかをチェックする際の一般的な方針として最も適切なものはどれか？{
=クラスタごとの特徴量の分布やラベル（もしあれば）を確認し、解釈可能な構造になっているか検討する
~クラスタ中心が必ず原点になるように変換する
~クラスタサイズがすべて同じになることを確認する
~クラスタ数が最大になるように設定する
}

// クラスター分析と教師あり学習の違い
::Q1.10 クラスター分析と分類::クラスター分析と教師あり分類（例: ロジスティック回帰）の違いとして最も適切な説明はどれか？{
=クラスター分析はラベルなしデータからグループ構造を見つけるのに対し、教師あり分類は既知のラベルを予測する
~クラスター分析は必ずラベル付きデータが必要である
~教師あり分類では距離を一切用いない
~両者はまったく同じ手法であり、呼び方が異なるだけである
}

// PCAの目的
::Q1.11 主成分分析の目的::主成分分析(PCA)の主な目的として最も適切なものはどれか？{
=高次元の相関のある変数を、情報をなるべく保ったまま低次元の直交ベクトル空間に写像すること
~目的変数との線形関係を推定すること
~クラスラベルを用いて最良の分離境界を求めること
~時系列の自己相関をモデル化すること
}

// 共分散行列と主成分
::Q1.12 共分散行列の固有値::PCAにおいて、共分散行列の固有値と固有ベクトルの組はそれぞれ何を表すか？{
=固有値が主成分の分散、固有ベクトルが主成分の向きを表す
~固有値が主成分の平均、固有ベクトルが外れ値を表す
~固有値がサンプル数、固有ベクトルが相関係数を表す
~固有値が誤差分散、固有ベクトルがクラスタ中心を表す
}

// 寄与率と累積寄与率
::Q1.13 累積寄与率::主成分分析で「累積寄与率」を用いる主な目的として最も適切なものはどれか？{
=全体の分散のうち、何次元目までの主成分でどれだけ説明できているかを評価するため
~各主成分の平均値を比較するため
~クラスラベルを予測する精度を測るため
~サンプル数を推定するため
}

// 標準化 vs 共分散行列／相関行列
::Q1.14 相関行列でのPCA::変数ごとにスケールが大きく異なる場合、共分散行列ではなく相関行列に基づいてPCAを行う意図として最も適切なものはどれか？{
=各変数を標準化したうえで、スケールに依存しない構造を抽出するため
~変数間の相関を強制的に0にするため
~外れ値を完全に除去するため
~主成分得点を0か1に離散化するため
}

// 主成分得点
::Q1.15 主成分得点の解釈::主成分得点（各サンプルを主成分空間に写像した座標）の散布図を見る主な目的として最も適切なものはどれか？{
=低次元空間上でサンプル同士の類似性やクラスタ構造を可視化するため
~元の次元でのユークリッド距離を直接計算するため
~時系列の周期性を検出するため
~ラベルのないデータにラベルを付与するため
}

// PCAとクラスター分析の関係
::Q1.16 PCA＋クラスタリング::高次元データに対して「PCAで次元削減した後にクラスタリングを行う」というパイプラインの利点として最も適切なものはどれか？{
=次元を削減してノイズを減らし、クラスタリングの安定性や可視化のしやすさを高められる
~クラスタリングの結果が必ず真のクラスラベルと一致する
~クラスタ数を自動的に決められる
~外れ値が必ず消える
}

// カーネルPCAの動機
::Q1.17 カーネルPCA::カーネル主成分分析を用いる主な動機として最も適切なものはどれか？{
=線形PCAでは捉えにくい非線形構造を、高次元特徴空間での線形PCAとして扱うため
~主成分の分散を必ず等しくするため
~サンプル数よりも次元数を減らさないため
~固有値をすべて1にするため
}

// カーネルトリック
::Q1.18 カーネルトリックの利点::カーネル法における「カーネルトリック」の利点として最も適切なものはどれか？{
=高次元特徴空間での内積を、元の空間で定義されたカーネル関数で直接計算できる
~高次元空間への写像を明示的に計算しなければならない
~必ず線形分離可能になる
~サンプル数を増やさなくても汎化性能が向上することが保証される
}

// ガウスカーネルのパラメータ
::Q1.19 ガウスカーネルの幅::ガウスカーネルのパラメータ（幅）が極端に小さい場合に起こりやすい現象として最も適切なものはどれか？{
=個々のサンプルの影響範囲が狭くなりすぎ、過度に局所的な構造を捉えて過学習しやすくなる
~すべてのサンプルがほぼ同じ特徴ベクトルになる
~カーネル行列が単位行列に近づき、情報が失われる
~主成分の分散が必ず0になる
}

// 次元削減の副作用
::Q1.20 次元削減のトレードオフ::次元削減を行うことで生じるトレードオフとして最も適切なものはどれか？{
=次元を減らすことでノイズが減り解釈しやすくなる一方、一部の情報が失われる可能性がある
~次元を減らすと必ず予測精度が向上する
~次元を減らすとサンプル数も減少する
~次元を減らすと外れ値が常に増える
}

// アソシエーション分析の目的
::Q1.21 アソシエーション分析の目的::アソシエーション分析（バスケット分析）の主な目的として最も適切なものはどれか？{
=一緒に現れやすいアイテムの組合せルールを発見し、推薦や販促などに活用すること
~時系列のトレンドと季節性を分解すること
~ラベル付きデータで分類境界を学習すること
~主成分を用いて次元削減すること
}

// 支持度・確信度・リフト
::Q1.22 支持度・確信度・リフト::アソシエーションルール A ⇒ B における支持度・確信度・リフトの説明として正しいものをすべて選べ。{
~%33.33333% 支持度は「全取引のうち A と B を同時に含む取引の割合」である
~%33.33333% 確信度は「A を含む取引のうち B も含む取引の割合」である
~%33.33333% リフトは「A と B が独立な場合と比べてどれだけ一緒に出やすいか」を表す指標である
~%-100% 支持度は「A を含む取引のうち B を含む取引の割合」である
}

// 支持度しきい値の影響
::Q1.23 支持度しきい値::支持度のしきい値を高く設定しすぎた場合に起こりやすい問題として最も適切なものはどれか？{
=興味深いが出現頻度の低いルールが見落とされてしまう
~全てのルールが常に残ってしまう
~リフトが1のルールだけが残る
~確信度が必ず低くなる
}

// 確信度の偏り
::Q1.24 確信度の落とし穴::A ⇒ B の確信度が高いが、B 自体が多くの取引に含まれている場合に注意すべき点として最も適切なものはどれか？{
=B の出現がもともと多いため、A と B の組み合わせが特に強い関係を持つとは限らない
~確信度が高ければ常に強い関連があるとみなせる
~支持度が低ければリフトは必ず1以下になる
~確信度はBの出現頻度とは無関係である
}

// リフト値の解釈
::Q1.25 リフト>1の意味::アソシエーションルール A ⇒ B のリフト値が1より大きい場合の解釈として最も適切なものはどれか？{
=A と B は独立である場合よりも一緒に現れやすい
~A と B は必ず因果関係にある
~A と B は独立である
~A が出現すると必ず B も出現する
}

// ルールの向き
::Q1.26 ルールの非対称性::アソシエーションルール A ⇒ B と B ⇒ A について正しい説明はどれか？{
=一般に A ⇒ B と B ⇒ A では確信度が異なるため、ルールの有用性も異なりうる
~A ⇒ B と B ⇒ A は常に同じ支持度と確信度を持つ
~A ⇒ B のリフトが1なら B ⇒ A のリフトは必ず0になる
~A ⇒ B が有用なら必ず B ⇒ A も有用である
}

// Aprioriアルゴリズム
::Q1.27 Aprioriの枝刈り::Aprioriアルゴリズムで「もしあるアイテム集合が頻出でなければ、その上位の集合も頻出にはなりえない」という性質を利用する主な利点として最も適切なものはどれか？{
=探索空間を効率的に削減し、計算コストを大幅に減らせる
~常にすべてのアイテム組み合わせを列挙できる
~支持度しきい値の設定が不要になる
~リフト値を計算しなくてよくなる
}

// アソシエーションと因果
::Q1.28 アソシエーションと因果::アソシエーション分析で発見されたルールから直接には分からないものとして最も適切なものはどれか？{
=アイテム間の因果関係
~アイテムの共起パターン
~同時に購入されやすい商品の組み合わせ
~頻出するアイテム集合
}

// 負の関連の発見
::Q1.29 負の関連::A と B がほとんど一緒に現れない（同時出現が独立な場合よりも明らかに少ない）というパターンを見つけたい場合、指標として最も有用なのはどれか？{
=リフト値（1より十分小さい値）
~支持度（高い値）
~確信度（高い値）
~サンプル数（大きい値）
}

// 実務でのルール選定
::Q1.30 ルールの実務利用::アソシエーションルールを実務に活用する際に考慮すべき点として最も適切なものはどれか？{
=ビジネス上の意味や施策との関係を踏まえ、支持度・確信度・リフトだけでなく解釈可能性や実行可能性も評価する
~リフト値が最大のルールだけを自動的にすべて採用すればよい
~支持度が低いルールは例外なく無視すべきである
~データさえあればビジネス側の意図は考慮する必要がない
}
