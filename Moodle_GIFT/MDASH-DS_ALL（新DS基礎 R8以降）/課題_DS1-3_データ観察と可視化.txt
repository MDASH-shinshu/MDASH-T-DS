// 量的・質的データの分類
::Q1.1 データの種類::次のうち、「量的データ」の例として最も適切なものはどれか？{
=1日の歩数
~職業分類（会社員・学生・無職など）
~血液型（A, B, O, AB）
~好きな色（赤・青・緑など）
}

// 比率・間隔データ
::Q1.2 比率尺度と間隔尺度::次のうち、「比率尺度」のデータに該当するものをすべて選べ。{
~%25% 身長(cm)
~%25% 体重(kg)
~%25% 所持金額(円)
~%25% 1日の消費カロリー(kcal)
}

// 比率・間隔データの判別
::Q1.3 西暦と気温::次のうち、「間隔尺度」として扱うのが適切なものはどれか？{
=西暦年（例: 1990年, 2000年）
~身長(cm)
~一月あたりの売上金額(円)
~通学時間(分)
}

// 名義・順序尺度
::Q1.4 質的データの尺度::次のうち、「順序尺度」の例として最も適切なものはどれか？{
=アンケートの満足度(1～5)「とても不満〜とても満足」
~都道府県名
~血液型
~学生番号
}

// クロス集計の読み取り
::Q1.5 クロス集計表の解釈::あるクロス集計表で、「性別×購買有無」の度数が示されている。この表から直接読み取れる内容として最も適切なものはどれか？{
=性別ごとの購買人数の比較
~性別が購買の原因になっているかどうか
~購買の将来予測
~購買者の平均年収
}

// クロス集計と平均値
::Q1.6 クロス集計と集約指標::クロス集計表において「平均値」「標準偏差」などを併記する目的として適切なものはどれか？{
=単なる件数だけでなく、量的データの分布の特徴も比較するため
~度数分布表を作らなくてよくするため
~質的データを量的データに変換するため
~回帰分析を必ず実行するため
}

// 度数分布表とヒストグラム
::Q1.7 度数分布表の目的::度数分布表を作成する主な目的として最も適切なものはどれか？{
=連続的なデータの分布の形や偏りを把握するため
~データの順序を完全に破壊するため
~外れ値を必ず取り除くため
~平均値だけで要約するため
}

// 階級幅の選び方
::Q1.8 階級幅の粗さ::ヒストグラムの階級幅を極端に大きく設定した場合に生じやすい問題として最も適切なものはどれか？{
=データの細かな分布の違いが見えなくなる
~外れ値だけが強調されすぎる
~棒の本数が増えすぎて読みにくくなる
~度数分布表が作成できなくなる
}

// 階級幅の細かさ
::Q1.9 階級幅の細かさ::階級幅を極端に小さく設定したヒストグラムで生じやすい問題をすべて選べ。{
~%50% 棒の本数が増えすぎてパターンが見えにくくなる
~%50% 度数が0の階級が多くなり、分布がギザギザになる
~%-100% 平均値が変わってしまう
}

// 不等間隔の階級
::Q1.10 不等間隔ヒストグラム::階級幅が不等なヒストグラムを作るとき、棒の高さを「度数」ではなく「度数／階級幅」で表す必要がある主な理由はどれか？{
=棒の面積が度数に比例するようにして分布を正しく比較するため
~計算手順を複雑にするため
~外れ値を自動的に除外するため
~中央値を正確に求めるため
}

// 最頻階級の解釈
::Q1.11 最頻階級の意味::ヒストグラムで「最頻階級」を見ることにより分かることとして最も適切なものはどれか？{
=最も多くのデータが集中している範囲
~最大値と最小値の差
~平均値の正確な値
~標準偏差の大小
}

// 分布の形状
::Q1.12 分布の左右非対称性::あるヒストグラムで、右側の裾が長く伸びている。このような分布の特徴として適切な説明はどれか？{
=右に裾を引く(右裾が長い)分布であり、少数の大きな値が存在する
~左に裾を引く分布であり、小さい外れ値が多い
~完全に対称な分布である
~一様分布である
}

// 外れ値検出
::Q1.13 外れ値候補::ヒストグラムを見て外れ値候補を検出する際に注意すべき点として最も適切なものはどれか？{
=サンプルサイズや尺度を考慮し、本当に異常な観測かどうかを慎重に判断する必要がある
~平均値から少しでも離れた値はすべて外れ値とみなす
~どのような分布でも、最頻階級以外はすべて外れ値である
~外れ値は常に除去しなければならない
}

// 散布図と相関
::Q1.14 散布図の読み取り::散布図を作成したところ、「右上がり」の点の並びが見られた。このとき解釈として最も適切なものはどれか？{
=2つの変数の間に正の相関がある可能性がある
~2つの変数の間に因果関係が必ず存在する
~2つの変数の間に負の相関がある
~2つの変数は完全に無関係である
}

// 相関と因果の区別
::Q1.15 相関と因果::散布図や相関係数を用いてわかることとして最も適切なものはどれか？{
=変数間に線形的な関係が「ありそうかどうか」
~一方の変数が他方の変数の原因であるかどうか
~将来の値を完全に予測できるかどうか
~変数がすべて独立であるかどうか
}

// 散布図行列
::Q1.16 散布図行列の目的::散布図行列を用いる主な目的として最も適切なものはどれか？{
=多変量データの中で、どのペアに強い関係がありそうかを俯瞰的に見るため
~単一の変数の分布のみを詳細に観察するため
~時系列変化だけを追跡するため
~因果モデルをそのまま表現するため
}

// 3次元散布図
::Q1.17 3次元散布図の難しさ::3次元散布図を用いる際の課題として最も適切なものはどれか？{
=視点によって印象が変わりやすく、関係性の把握が難しい
~2次元平面上で表現できない
~相関係数が計算できない
~データ件数が必ず減少してしまう
}

// グラフの選択
::Q1.18 グラフの選び方::「月ごとの平均気温の推移」を表現したいとき、最も適切なグラフはどれか？{
=折れ線グラフ
~円グラフ
~ヒストグラム
~散布図行列
}

// 構成比の可視化
::Q1.19 構成比の表現::ある年度における電源構成（火力・原子力・再エネなど）の割合を比較したいとき、適切なグラフをすべて選べ。{
~%50% 円グラフ
~%50% 帯グラフ（100%積み上げ棒）
~%-100% 折れ線グラフ（時間変化グラフ）
}

// 時系列の誤解
::Q1.20 時系列棒グラフの注意点::売上の推移を棒グラフで表すとき、「縦軸の下限を0からではなく途中からにする」ことによる主な問題は何か？{
=実際以上に変化が大きく見えてしまう
~平均値が変化してしまう
~最大値と最小値が入れ替わる
~データ件数が少なく見える
}

// 相対度数と絶対度数
::Q1.21 相対度数の利点::度数分布を相対度数（割合）で表現する利点として最も適切なものはどれか？{
=サンプルサイズの異なる集団間で分布を比較しやすくなる
~平均値を計算する必要がなくなる
~標準偏差が必ず1になる
~外れ値が自動的に除外される
}

// パレート図
::Q1.22 パレート図::パレート図の特徴として正しいものをすべて選べ。{
~%33.33333% 項目を大きい順に並べた棒グラフである
~%33.33333% 累積相対度数の折れ線グラフを併記する
~%33.33333% 重要な少数の要因に注目するのに使われる
~%-100% 時系列変化を表すだけのグラフである
}

// 箱ひげ図の解釈
::Q1.23 箱ひげ図::箱ひげ図において「箱」の上端と下端が表すものは何か？{
=第3四分位数と第1四分位数
~最大値と最小値
~平均値と中央値
~第2四分位数と第4四分位数
}

// 箱ひげ図と外れ値
::Q1.24 箱ひげ図の外れ値::箱ひげ図において、ひげから離れた点としてプロットされる値の意味として最も適切なものはどれか？{
=四分位範囲から大きく離れた外れ値の候補
~最頻値
~中央値
~必ず誤ったデータ
}

// ヒートマップ
::Q1.25 ヒートマップの用途::ヒートマップを用いる目的として最も適切なものはどれか？{
=値の大小を色の濃淡などで表し、パターンやクラスタを視覚的に把握するため
~時間変化のみを表現するため
~外れ値だけを強調するため
~ネットワーク構造のみを表現するため
}

// 相関行列とヒートマップ
::Q1.26 相関行列の可視化::多変量データの相関係数をまとめた相関行列をヒートマップで表示する利点として最も適切なものはどれか？{
=どの変数間で強い正・負の相関があるか一目で把握できる
~散布図を全く作成しなくても因果関係が分かる
~相関係数を計算しなくてもよくなる
~標本数が自動的に増える
}

// 地図による可視化
::Q1.27 地図上の可視化::都道府県別の人口密度や感染者数などを地図上で色分けして表示する主な利点として最も適切なものはどれか？{
=地域ごとの空間的な偏りやクラスターを直感的に把握できる
~地域差を完全に打ち消して平均化できる
~時系列変化を表現できない
~数値の正確な値を読み取るのに最適である
}

// ネットワーク可視化
::Q1.28 ネットワークグラフ::SNSのフォロー関係や空港間の路線を可視化するために用いられる「ネットワークグラフ」の特徴として適切なものはどれか？{
=ノードとリンクで関係性の構造を表し、中心性やコミュニティ構造を把握できる
~時系列の変化のみを表すグラフである
~分布の形状だけを示すグラフである
~空間的な位置情報は必ず含まれる
}

// 軌跡の可視化
::Q1.29 軌跡データ::スポーツのボールの軌跡や人の移動軌跡を可視化することによって得られる知見として最も適切なものはどれか？{
=動き方のパターンや典型的な経路、異常な動きなどを視覚的に把握できる
~平均値だけで十分に把握できる情報を冗長に表現している
~相関係数が常に1になる
~分布の裾がわからなくなる
}

// 可視化の目的
::Q1.30 可視化の5つの視点::データ可視化の目的の観点として、「比較」「変化」「構成比」「分布」「相関」を意識することの利点として最も適切なものはどれか？{
=目的に応じて適切なグラフを選択し、解釈の焦点を明確にできる
~どのグラフを使っても同じ結果が得られるとみなせる
~平均値だけを見て判断してよいと確認できる
~数値の一覧表を見る必要がなくなる
}
